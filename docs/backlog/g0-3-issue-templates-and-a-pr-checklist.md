# G0.3 — Issue templates and a PR checklist

**Stage:** Stage 0 — Project foundation

## Motivation

Contributions should arrive in the shape the roadmap expects.

## Scope

- Add `.github/ISSUE_TEMPLATE/` with a 'roadmap task' template mirroring the backlog fields (motivation, scope, implementation notes, acceptance criteria, tests, dependencies).
- Add `.github/pull_request_template.md` with the CONTRIBUTING checklist.

## Implementation notes

- Keep templates short; link to `CONTRIBUTING.md`.

## Acceptance criteria

- New issues and PRs open with the template pre-filled.

## Tests required

- n/a.

## Dependencies

_None._
